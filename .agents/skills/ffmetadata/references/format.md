# ffmetadata: the format, its keys, each container's mapping

Researched at FFmpeg n8.1.2: `doc/metadata.texi`; `libavformat/ffmetadec.c`,
`ffmetaenc.c`, `ffmeta.h`; `avformat.h` (keys); the muxers' tables (each row
below names its file). Measured by `../scripts/measure.py` (its output is the
tables marked *measured*).

## The format

ffmpeg's text form of a file's tags and chapters: a demuxer and a muxer named
`ffmetadata` ("FFmpeg metadata in text"), UTF-8. Extension `.ffmeta`, the
muxer's (`ffmetaenc.c`); the demuxer has none -- it probes the first bytes.

| Rule                                                                                                                                                                                        | Source                         |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ |
| Header `;FFMETADATA` then a version, `1`. The probe checks `;FFMETADATA` alone; the line is then a comment                                                                                  | `ffmeta.h`, `ffmetadec.c`      |
| Global tags first; then `[STREAM]` and `[CHAPTER]` sections, each to the next or the end                                                                                                    | `metadata.texi`                |
| A section header is the whole line, exactly `[STREAM]` or `[CHAPTER]` (case matters)                                                                                                        | `ffmetadec.c` (`memcmp`)       |
| A tag is `key=value`, split at the first unescaped `=`; a line without one is ignored                                                                                                       | `ffmetadec.c` (`read_tag`)     |
| Lines starting with `;` or `#`, and empty lines, are skipped -- the line's first byte only                                                                                                  | `ffmetadec.c`                  |
| A backslash makes the next byte literal, any byte; a line ends at an unescaped `\n`, `\r\n` or `\r`                                                                                         | `ffmetadec.c`                  |
| Whitespace is the tag's: `k = v` is key `k`, value `v`                                                                                                                                      | `metadata.texi`                |
| A chapter: `TIMEBASE=num/den` (optional; default 1/1000000000), then `START=`, then `END=`, in that order                                                                                   | `ffmetadec.c` (`read_chapter`) |
| Its tags follow `END`. `[STREAM]` sections are the input's streams 0, 1, ... in order -- applied to an output's only by `-map_metadata:s:SPEC N:s:I` (`-map_metadata N` is the global tags) | `ffmetadec.c`; measured        |
| The writer escapes `#` `;` `=` `\` and newline -- not `\r`                                                                                                                                  | `ffmetaenc.c`                  |
| The writer: header `;FFMETADATA1`, global tags, a `[STREAM]` per stream (tagless too), chapters with `TIMEBASE`, `START`, `END` always                                                      | `ffmetaenc.c`                  |

*Measured*, each a file read by ffmpeg and written back by it:

| Written                                    | ffmpeg's reading                                                                                                                                                                      |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `k\=\;\#\\=a\=b\;c\#d\\e`                  | key `k=;#\`, value `a=b;c#d\e` -- back the same                                                                                                                                       |
| `k=line one\` + newline + `line two`       | one value of two lines -- back the same                                                                                                                                               |
| `k=a\nb` (a backslash, an `n`)             | `anb`: the backslash goes, the `n` stays                                                                                                                                              |
| `k=a` + CR + `b`                           | `a`, and `b` a line without `=`: dropped                                                                                                                                              |
| `k=a\` + CR + `b`                          | `a` CR `b`: kept -- only an escaped CR round-trips                                                                                                                                    |
| `Title=first`, then `title=second`         | `title=second`: keys match without case, the last wins                                                                                                                                |
| `k = v`                                    | key `k`, value `v`                                                                                                                                                                    |
| `k=`                                       | a tag, its value empty -- back the same                                                                                                                                               |
| `=v`                                       | a tag, its key empty -- back the same                                                                                                                                                 |
| a chapter without `END`                    | an error logged; the line read in its place lost; back as `END=0`                                                                                                                     |
| `k=a` NUL `b`                              | `a`: the line ends at the `NUL`                                                                                                                                                       |
| `k=x\\` + newline + `next=1`               | `x\` + newline + `next=1`: the line reader looks one byte back, so a line break after an escaped `\` is escaped to it -- no value can end in `\` and be followed by a line            |
| `k=x\\` at the file's end, no newline      | `x\`: read right                                                                                                                                                                      |
| `just text`                                | dropped, silently                                                                                                                                                                     |
| `; a comment\` + newline + `k=swallowed?`  | both one comment: the tag is lost                                                                                                                                                     |
| `;x=y` the file's last line, no line break | a tag, key `;x`: comments are skipped only while the file has more; a chapter's tag if it follows one                                                                                 |
| `[chapter]` (lower case) and its lines     | no chapter: `TIMEBASE`, `START`, `END`, `title` become global tags                                                                                                                    |
| a chapter without `START`                  | an error logged; start 0 (or the last chapter's end), kept                                                                                                                            |
| a chapter without `TIMEBASE`               | nanoseconds                                                                                                                                                                           |
| `TIMEBASE=1`                               | `1/1000000000`: `sscanf` read the numerator alone, the denominator stays                                                                                                              |
| `START=12abc`                              | 12: `sscanf` stops at the first non-digit; a sign and spaces are read too                                                                                                             |
| lines ended by CR alone                    | a tag's line ends at CR, a chapter's time lines do not (`get_line` ends at LF): the chapter broken, `START=0` `END=0`, its tags lost                                                  |
| `START=-5`                                 | read as -5; ffmpeg's command line clamps every chapter it copies -- start at least 0, end at most `-t`, chapters wholly outside dropped (`fftools/ffmpeg_mux_init.c` `copy_chapters`) |
| `;FFMETADATA2`                             | probed and read: the version is not checked                                                                                                                                           |
| no header                                  | not probed (read only with `-f ffmetadata`)                                                                                                                                           |

ffmpeg sets `encoder` (`Lavf...`) on every file it writes: a given `encoder`
is replaced.

Exported from a media file (`-f ffmetadata`), by default only the global tags and the
chapters: `-map 0 -c copy` adds a `[STREAM]` section a stream, its tags; `-map_metadata
0:s:0` makes a stream's tags the global ones -- Ogg's, Vorbis's and Opus's tags are their
stream's (measured: the default export of an `.ogg` holds `encoder` alone).

## Keys

`avformat.h`'s generic keys -- demuxers export a container's tags under these
where they have them, and leave the rest as stored: `album`, `album_artist`,
`artist`, `comment`, `composer`, `copyright`, `creation_time`, `date`, `disc`,
`encoder`, `encoded_by`, `filename`, `genre`, `language`, `performer`,
`publisher`, `service_name`, `service_provider`, `title`, `track`,
`variant_bitrate`. `track` and `disc` may be `current/total`; dates ISO 8601.
Modifiers, appended in this order: `-` and an ISO 639-2/B language
(`title-eng`), then `-sort` (`artist-sort`). Keys are unique, flat, UTF-8.
