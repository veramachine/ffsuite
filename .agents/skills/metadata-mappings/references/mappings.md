# ffmetadata, Vorbis comments, cue sheets: the mappings

The skill's full tables ([SKILL.md](../SKILL.md)): how each format's elements map
to the others', and what cannot cross, each row sourced. Recorded first for
ffsuite's phase 6 (6.6.1, `docs/ffman-phase6.md`); ffmeta's converter
(`packages/ffmeta/src/ffmeta/convert.py`) maps by these rows, every loss noted;
where it departs from ffmpeg's or no reader's row -- `CATALOG` and a track's
`ISRC` kept, a chapter's URL, `COMMENT` with `DESCRIPTION` -- the skill says so.
The formats themselves are the skills' ([ffmetadata](../../ffmetadata/SKILL.md),
[vorbiscomment](../../vorbiscomment/SKILL.md), [cue](../../cue/SKILL.md)).

Sources, at nixpkgs' pins: FFmpeg n8.1.2 (`vorbiscomment.c`, `oggparsevorbis.c`,
`oggenc.c`, `metadata.c`, `fftools/ffmpeg_mux_init.c`); mpv 0.41.0
(`demux/cue.c`, `demux/demux_cue.c`, `demux/demux.c`, `misc/charset_conv.c`);
Kodi 21.2 (`xbmc/CueDocument.cpp`); cuetools 1.4.1 (`cuetag.sh`, `cueprint.c`;
built and run); libcue 2.3.0 (the cue skill); MusicBrainz Picard's tag
definitions (`picard-docs`, `variables/tags_*.rst`). Measured:
[`measure.py`](../scripts/measure.py) (`python3 measure.py FFMPEG CUETAG
VORBISCOMMENT METAFLAC CUEDUMP`), parts A-H below. "Source" is read in code;
"measured" is that script's output.

Every direction, input to target:

| From \ to  | ffmetadata                                 | Vorbis                                  | cue                               |
| ---------- | ------------------------------------------ | --------------------------------------- | --------------------------------- |
| ffmetadata | the ffmetadata skill (ffmpeg's round trip) | table 1 (A, F)                          | table 3 (H)                       |
| Vorbis     | table 1 (B, F)                             | the vorbiscomment skill (its text form) | table 3 (H)                       |
| cue        | table 2 (C, D, E, G)                       | table 2 (C, D, G)                       | the cue skill (its writing rules) |

## 1. ffmetadata and Vorbis comments

ffmpeg converts between them (reading one, writing the other); every row is its
behaviour, both ways.

| Element                                 | ffmetadata -> Vorbis                                                                                                                                                 | Vorbis -> ffmetadata                                                                                                | Cannot cross                                                                                       | Source                                                                   |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| A key                                   | written as given: `title=T` stays lower-case, `Custom Key` keeps its space                                                                                           | the name as written: `ARTIST`, `Title` -- not made generic                                                          | nothing (both compare without case)                                                                | `vorbiscomment.c`; A, B                                                  |
| `album_artist` `track` `disc` `comment` | `ALBUMARTIST` `TRACKNUMBER` `DISCNUMBER` `DESCRIPTION`                                                                                                               | the reverse                                                                                                         | --                                                                                                 | `ff_vorbiscomment_metadata_conv`; A, B                                   |
| `COMMENT` with `DESCRIPTION`            | --                                                                                                                                                                   | both read (`COMMENT`, `comment`: ffprobe shows both); ffmpeg's output keeps **the first in order**, drops the other | one of the two, through ffmpeg                                                                     | `metadata.c` (`AV_DICT_MULTIKEY`), fftools (`AV_DICT_DONT_OVERWRITE`); B |
| `encoded_by` and `ENCODEDBY`            | `encoded_by` written as is                                                                                                                                           | `ENCODEDBY`, `ENCODED_BY` kept apart, neither made `encoded_by`                                                     | the meaning, unless a converter maps them (Picard's name: `ENCODEDBY`)                             | B; Picard                                                                |
| `encoder`                               | ffmpeg writes its own (`Lavf...`, `Lavc... libopus`)                                                                                                                 | a tag like any                                                                                                      | the source's                                                                                       | fftools; A                                                               |
| Repeated names                          | `artist=A;B`: one comment, not split                                                                                                                                 | `ARTIST=A`, `ARTIST=B` -> `ARTIST=A\;B`                                                                             | how many values: `;` in a value and two values read the same; ffmetadata holds one value a key     | `oggparsevorbis.c` (`AV_DICT_APPEND`); A, B                              |
| A chapter's start                       | Opus only (`oggenc.c`: Vorbis, Theora, FLAC pass none); any time base to `HH:MM:SS.mmm`, **seconds rounded**: 113/75 s (1.507) written `00:00:02.507`, a second late | `TIMEBASE=1/1000`, exact                                                                                            | the fraction past a millisecond; ffmpeg's second (the vorbiscomment skill: write them by division) | `vorbiscomment.c`; A, B                                                  |
| A chapter's end                         | not written                                                                                                                                                          | the next start, or the duration                                                                                     | `END`                                                                                              | `vorbiscomment.c`; A, B                                                  |
| A chapter's title                       | `CHAPTERxxxNAME`                                                                                                                                                     | `title`                                                                                                             | --                                                                                                 | A, B                                                                     |
| A chapter's other tags                  | `CHAPTERxxx<key>` (`CHAPTER000artist`)                                                                                                                               | a plain tag of the file, as is `CHAPTERxxxURL`                                                                      | every chapter tag but the title                                                                    | `oggparsevorbis.c` (`ogm_chapter`); A, B                                 |
| Chapters, numbered                      | by position, `000`-`999`; past 1000 dropped                                                                                                                          | ids from the number                                                                                                 | the ids; chapters past 1000                                                                        | `vorbiscomment.c`                                                        |
| Chapters, no tags                       | written while any tag is (an encode always has its encoder's); a copy with `-fflags +bitexact` writes **no comment: the chapters lost**                              | --                                                                                                                  | the chapters, in that case                                                                         | `vorbiscomment.c` (`if (m)`); A                                          |
| `[STREAM]` sections                     | Ogg: the global tags merged into each stream's comments, **the stream's winning** (`title=S` over `title=T`); FLAC: the global tags only, `[STREAM]` lost            | Ogg: stream tags, exported only with `-map_metadata 0:s:0`; FLAC: global                                            | which tag was global and which the stream's; a FLAC stream's own tags                              | `oggenc.c` (`AV_DICT_DONT_OVERWRITE`), `flacenc.c`; A, B                 |
| `-map_metadata -1`                      | drops the chapters' titles too (every manual flag set): `CHAPTER000` without its `NAME`; `-map_metadata:g -1` drops only the global tags                             | --                                                                                                                  | --                                                                                                 | fftools `copy_metadata`; A                                               |
| A key with `=` (`a\=b`)                 | written `a=b=v`: a reader splits it at the first `=` -- name `a`, value `b=v`                                                                                        | read back so: `a=b\=v` (no Vorbis name holds `=`)                                                                   | the key                                                                                            | F                                                                        |
| A key outside 0x20-0x7D (`título`)      | written as is: not a valid Vorbis name                                                                                                                               | read as is (ffmpeg checks no name)                                                                                  | the key, for readers that check (`vorbiscomment`, libFLAC)                                         | F; the vorbiscomment skill                                               |
| An empty value (`empty=`)               | written `empty=`                                                                                                                                                     | dropped (and an empty name)                                                                                         | it, back                                                                                           | F                                                                        |
| A value on several lines                | a comment with LF                                                                                                                                                    | `\` before each line break: exact                                                                                   | --                                                                                                 | F                                                                        |
| A value with CR                         | (ffmetadata cannot hold CR)                                                                                                                                          | written raw: the CR ends the ffmetadata line                                                                        | it                                                                                                 | F; the ffmetadata skill                                                  |
| A language suffix (`title-eng`)         | written `title-eng`                                                                                                                                                  | `title-eng`                                                                                                         | its meaning (Vorbis has none)                                                                      | F                                                                        |
| A cover picture                         | --                                                                                                                                                                   | `METADATA_BLOCK_PICTURE` is no tag to ffmpeg: an attached-picture stream                                            | it, in ffmetadata                                                                                  | F                                                                        |
| A whole cue sheet (`CUESHEET`)          | written, lines kept                                                                                                                                                  | a value on several lines, exact                                                                                     | -- (a cue sheet, carried)                                                                          | F                                                                        |
| The vendor string                       | --                                                                                                                                                                   | not exported                                                                                                        | it                                                                                                 | the vorbiscomment skill                                                  |

a cue to tags do, and where none does, what a field means.

| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------ |

## 3. ffmetadata or Vorbis into cue

No tool writes a cue sheet from either (ffmpeg, metaflac, cuetools: none). These
rows are the cue skill's writing rules applied to tables 1-2 read backwards; H
builds each sheet from them alone and reads it back -- libcue, metaflac with
ffmpeg's chapters of its block, cuetag.sh -- matching every value but those
noted.

| From                                                                                | Cue                                                                                                                   | Read back                                                                    | Cannot cross                                                                     | Source                                      |
| ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------- |
| `album` / `ALBUM`                                                                   | disc `TITLE "..."`                                                                                                    | libcue, cuetag (`ALBUM`)                                                     | a `"`, a line break or a final `\`; over 80 characters noted                     | H; the cue skill (`\`)                      |
| `album_artist` / `ALBUMARTIST`                                                      | disc `PERFORMER "..."`                                                                                                | libcue                                                                       | as above; `artist` alone has no disc field                                       | H; `CueDocument.cpp`                        |
| `genre` / `GENRE`                                                                   | `REM GENRE`, quoted when it holds a space                                                                             | libcue                                                                       | a `"` or a final `\` with a space                                                | H; the cue skill (`\`)                      |
| `date` / `DATE`, `disc` / `DISCNUMBER`                                              | `REM DATE 1991`, `REM DISCNUMBER 1` -- **never quoted**: Kodi reads a number only when its first character is a digit | libcue (`DATE`)                                                              | --                                                                               | H; `CueDocument.cpp` (`ExtractNumericInfo`) |
| `REPLAYGAIN_ALBUM_*`                                                                | `REM REPLAYGAIN_ALBUM_GAIN -7.03 dB`, **unquoted** (Kodi reads from a fixed column)                                   | libcue (the first word)                                                      | --                                                                               | H; `CueDocument.cpp`                        |
| `BARCODE`, 13 digits                                                                | `CATALOG`                                                                                                             | metaflac's block                                                             | any other length                                                                 | H                                           |
| A chapter's start                                                                   | `INDEX 01`, to the nearest frame                                                                                      | libcue, metaflac, ffmpeg: 0, 257693, 542987 ms back exactly                  | up to 6.67 ms (D)                                                                | H                                           |
| A first chapter after 0                                                             | track 1's `INDEX 00 00:00:00` before its `INDEX 01`                                                                   | libcue: track 1 at 30 s; **ffmpeg's FLAC block: at 0** (its `INDEX 00` rule) | --                                                                               | H                                           |
| A chapter's end                                                                     | the next track's start                                                                                                | --                                                                           | a gap or an overlap; the last chapter's end                                      | H                                           |
| Chapters' order, count                                                              | sorted; tracks `01`-`99`                                                                                              | 99 back of 100                                                               | past 99                                                                          | H                                           |
| No chapters                                                                         | one track at 0                                                                                                        | --                                                                           | --                                                                               | H                                           |
| A chapter's title                                                                   | track `TITLE "..."`                                                                                                   | libcue, cuetag (`TITLE`)                                                     | a `"`, a line break or a final `\` (the title dropped); over 80 characters noted | H; the cue skill (`\`)                      |
| A chapter's `performer` (ffmetadata)                                                | track `PERFORMER "..."`                                                                                               | libcue, cuetag                                                               | Vorbis has none to give                                                          | H                                           |
| A chapter's other tags; streams' tags; every other tag (`composer`, `comment`, ...) | --                                                                                                                    | --                                                                           | them (a `REM` line no reader reads)                                              | H; table 2                                  |
| A `CUESHEET` tag                                                                    | the cue sheet itself                                                                                                  | --                                                                           | --                                                                               | F                                           |
| The file                                                                            | `FILE "<the media's name>" WAVE`; UTF-8, no BOM, LF                                                                   | --                                                                           | --                                                                               | the cue skill                               |

mpv reads a `.cue` in UTF-8, a BOM's charset, or else the charset uchardet
guesses (nixpkgs builds mpv with it), converted (`charset_conv.c`).

## Measured (`measure.py`)

- **A.** An ffmetadata file into `.opus`, `.ogg`, `.flac`: the comments as above;
  Opus' chapter at 113/75 s written `00:00:02.507`; chapters with no tags kept
  by every encode and a plain copy, lost by a copy with `-fflags +bitexact`;
  `-map_metadata -1` writes the chapter without its title.
- **B.** Comments into ffmetadata: `ARTIST=A\;B`; `COMMENT` and `DESCRIPTION`,
  either order, the first kept; `ENCODEDBY`, `ENCODED_BY` apart; `CHAPTER000URL`,
  `CHAPTER000ARTIST` plain tags; Ogg's tags only with `-map_metadata 0:s:0`.
- **C.** cuetag.sh on an EAC-style sheet: track 1 `TITLE`, `ALBUM`,
  `TRACKNUMBER`, `TRACKTOTAL`, `ARTIST`, `PERFORMER`, `ISRC`; track 2 (no
  `PERFORMER`) no artist; nothing from `REM`, `CATALOG`, `SONGWRITER`.
- **D.** Every frame to 100 hours: to milliseconds at most 1/3 ms off, back
  exact; of the milliseconds to an hour, 270,001 (7.5%) survive a cue's frames.
- **E.** `TIMEBASE=1/75`, `START=19327`: Matroska's chapter at 257.693333 s;
  written again by ffmpeg, `1/75` and `19327` unchanged.
- **F.** The edges both ways: `a=b=v`, read back as key `a`; `título` written
  and read back; `empty=` written and, back, dropped (`=noname` too); line breaks exact; CR raw into ffmetadata;
  `title-eng` as is; the picture an attached-picture stream; `CUESHEET` exact.
- **G.** cuetag.sh with libcue's commands: `ARTIST=Track Composer` (over the
  `PERFORMER`), `DESCRIPTION`, `GENRE`.
- **H.** Five sheets built by table 3 and read back: plain; a first chapter at
  30 s; a gap and an overlap; a `"`, a line break, 100 characters; 100 chapters
  -- each value back as the rows say, each loss noted.
